# Spooky Burst : prompts pour générer les graphismes

À utiliser avec Midjourney, Leonardo, DALL·E (ChatGPT) ou Ideogram. Copie chaque prompt tel quel.

## Règles importantes

1. **Même style pour tout.** Ajoute toujours le bloc de style ci-dessous à la fin de chaque prompt de symbole.
2. **Fond uni pour les symboles.** Demande un fond noir uni, ou transparent si l'outil le permet. Je détourerai moi-même si besoin.
3. **Un symbole par image**, centré, entier, avec de la marge autour. Rien de coupé, et aucun texte dans l'image.
4. **Taille :** au moins 1024 × 1024 pour les symboles, 1920 × 1080 pour les fonds, 1200 × 1600 pour la tuile.
5. Génère 3 ou 4 variantes par symbole et garde celles qui vont le mieux ensemble.
6. **Midjourney :** ajoute `--ar 1:1 --style raw --v 6` pour les symboles et `--ar 16:9` pour les fonds.

**Bloc de style (à coller à la fin de chaque symbole) :**

> premium online slot game symbol, Halloween theme, glossy semi-3D cartoon render, rich painted shading, strong rim light, soft glow, vibrant saturated colors, clean silhouette, centered, isolated on solid black background, no text, high detail, game asset

**Astuces :**
- Si l'outil accepte une **image de référence**, donne-lui la planche d'exemple (épées, potions, casque) comme modèle de style.
- Format conseillé : paysage 2:1 (par exemple 2048 × 1024), ou le plus grand format disponible.
- Le coin en haut à droite reste vide exprès : si la version gratuite ajoute son filigrane à cet endroit, je le couperai en découpant la planche.
